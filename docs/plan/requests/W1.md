# Requests to W1 (user web core)

## From W3 (operations + documents)
1. **BLOCKER — `OrgPaths` makes `params.header` required on every mutating tenant call.** Since the contract now declares the optional
   `Idempotency-Key` header, `StripParams` (src/core/api/types.ts) leaves `{ "Idempotency-Key"?: string }` and types it as a **required**
   `header`, so `api.POST(..., { body })` fails typecheck everywhere (organization/api.ts too). Suggested fix in `StripParams`:
   ```ts
   : Record<string, never> extends Omit<H, OrgHeaderName>
     ? Omit<P, "header"> & { header?: Omit<H, OrgHeaderName> }
     : Omit<P, "header"> & { header: Omit<H, OrgHeaderName> }
   ```
   W3 meanwhile passes `params: { header: {} , ... }` via `features/operations/api/params.ts` (`H`) — forward-compatible with the fix.
2. **CSP `frame-src`.** Document preview of PDFs from signed Supabase URLs needs `frame-src 'self' blob: https://*.supabase.co` (default-src
   'self' blocks the iframe). W3 currently shows images inline and opens PDFs in a new tab ("Open preview").
