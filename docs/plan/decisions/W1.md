# W1 — User web core: decisions

| # | Decision | Why |
|---|---|---|
| 1 | Two typed clients: `api` (raw `paths`, personal/public) and `createOrgClient(orgId)` typed with `OrgPaths` (contract paths with the required `X-Organization-ID` header stripped at type level). Feature code gets the org client from `useOrg().api`. | Header can't be forgotten or mismatched with the query key's `orgId`; calling a tenant route with the personal client fails typecheck. |
| 2 | Auth logic lives in a custom `fetch` passed to openapi-fetch (not middleware): attaches Bearer + org header, clones the request, on 401 `TOKEN_EXPIRED`/`UNAUTHENTICATED` does one single-flight `POST /auth/refresh` (`X-Requested-With: inaiflow`, `credentials: include`) and retries once; failure → `sessionStore.end("expired")` → `/login?next=…`. `/auth/*` responses are never retried. | Retry needs an un-consumed body clone; simplest correct place. |
| 3 | Session (`accessToken`, `user`, `impersonation`, `bootstrapped`) is a module-level store read via `useSyncExternalStore`. Never web storage; ESLint bans `localStorage`/`sessionStorage` except `core/prefs.ts` (last org slug, sidebar collapsed — non-sensitive). | Plan §3.2/§3.9. |
| 4 | Login/refresh token payload validated with zod (`readAccessToken`) before storage. | Defence against malformed responses (and the former TokenOut collision). |
| 5 | No Next middleware: client-side `RequireAuth` + `RedirectIfAuthenticated` with a calm full-screen loader; `safeNext()` only allows same-app relative `next` targets. | Tokens are memory-only, so the server can't know the session; prevents open redirects. |
| 6 | Tenant routes are `/o/[orgSlug]/…`; `TenantGate` resolves slug → `GET /me/organizations` → `GET /org/context`, with dedicated screens for not-member, `MFA_REQUIRED`, `ORG_SUSPENDED`, `MEMBERSHIP_EXPIRED`. | Spec §3.4 failure modes need clear copy. |
| 7 | Permissions: `resolveLevel(ctx, key)` (owner → FULL; missing → NONE; `module.*` → max of module, used only for nav). `<Can>`, `useCan`, `usePermission`. `is_owner` (an ownership fact from `/org/context`) gates Transfer ownership; role codes are never checked in components (the only role-code use is hiding `ORG_OWNER` from role pickers / matrix editing). | Skill rule 8. |
| 8 | Shortcut registry with scopes (`global` < pushed scopes, last pushed wins; ties → latest registration). Plain keys don't fire in inputs; modifier/F-keys/Esc do. Global: Alt+G (also Ctrl+K) palette, Alt+C create menu, `?` help. Create menu uses scope `create-menu` for letter/F-key picks. | Lets voucher screens own F4–F9/Ctrl+A/Esc. |
| 9 | Global error toasts via TanStack `MutationCache`/`QueryCache` (`meta.silentError` opt-out; `meta.successMessage` for success toasts). First-load query failures render inline `ErrorState`; 4xx are not retried. | Consistent, calm error UX with little code per feature. |
| 10 | Upload rule: ticket `headers` with Content-Type → raw PUT; else multipart field `file`. Local-storage URLs are rewritten same-origin. | Contract ambiguity (requests/contract.md W1-3). |
| 11 | Impersonation: `/impersonate#token=…&org_id=…` → token kept in memory, hash cleared, `GET /org/context` → `/o/<slug>`; no refresh, no personal space; reload ends the session (`/impersonate?ended=1`). Banner from `org/context.impersonation`. | Plan §3.4, admin launch. |
| 12 | Inter is self-hosted (`src/app/fonts/inter-latin-var.woff2`, OFL) via `next/font/local`; Google Sans Flex referenced in the CSS stack only. | `fonts.googleapis.com` is blocked in CI/sandbox, breaking `next build`. |
| 13 | CSP is nonce-free: `script-src 'self' 'unsafe-inline'` (+`'unsafe-eval'` in dev only), `style-src 'unsafe-inline'`; `SERVER_URL` origin added to `img-src`/`connect-src` for dev local storage. HSTS added. | Next App Router inline bootstrap needs it without nonces. |
| 14 | Org create wizard = 4 steps: Essentials → Tax registration → Financial year & workspace (slug check debounced, industry) → Review. Plan/autopay step from the design is omitted (payment gateway deferred, plan §4). GSTIN must match a numeric state code; PAN auto-filled from GSTIN. | Contract `OrgCreateIn` has no plan fields. |
| 15 | Member expiry is a date in the UI, sent as `YYYY-MM-DDT23:59:59Z`. Multi-email invite = one `POST /organization/invitations` per address. | Contract takes `datetime` and a single email. |
| 16 | Role pickers use `GET /organization/roles` when the user has `organization.roles_rbac:READ`, else roles seen on members. | `members:FULL` doesn't imply `roles_rbac:READ`. |
| 17 | ACL resource names come from module list endpoints (stock items, runs, folders (root level), godowns); if the lookup fails (no module READ) the dialog accepts a pasted id. | Per task. |
| 18 | Nav items point at the planned W2/W3 route paths (`nav-config.ts`, `create-items.ts`); W2/W3 may edit their own module's entries. Placeholder pages exist only for `/accounts`, `/operations`, `/documents`. | Lets streams land routes without touching shell code. |
| 19 | Notifications bell from the design is omitted (no notifications endpoint in the contract). | Contract first. |
