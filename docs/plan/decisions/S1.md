# S1 — Server foundation: decisions & deviations

1. **FORCE RLS + owner policy.** Every `org_id` table (+ `organizations` on `id`) has ENABLE+FORCE RLS, `tenant_isolation_<t>`
   (TO inaiflow_app, USING+WITH CHECK) and `owner_access_<t>` (TO the migrating role, `true`). FORCE alone would block
   the identity/admin/cron paths, which run as the table owner without `SET ROLE`. The app must therefore connect as the
   role that ran migrations (local: `inaiflow_owner`; Supabase: `postgres`). Policies use `NULLIF(current_setting(...), '')::uuid`
   (an unset-after-reset GUC is `''`, which would otherwise raise a cast error).
2. **Grants:** app role gets CRUD on tenant tables, `SELECT,INSERT,UPDATE` on organizations, `SELECT,INSERT` on org_audit_logs,
   `SELECT` on platform configs/plans/invoices, none on impersonation sessions, and **column-level** SELECT on users (no
   password_hash/mfa_secret). Append-only triggers on both audit tables (stop even the owner).
3. **gen_random_uuid()** instead of uuid-ossp; rates `NUMERIC(7,4)`; money/qty `NUMERIC(18,4)` (plan prices too).
4. **Sessions:** one `user_sessions` row per refresh token; `family_id` is the logical session = access-token `sid` =
   `SessionOut.id`. Rotation is an atomic `UPDATE … WHERE revoked_at IS NULL RETURNING` (no row locks); replay of a rotated
   token revokes the family. Added `revoke_reason`. Refresh issues `mfa = user.mfa_enabled` (enabling MFA revokes other sessions).
5. **Impersonation:** access token `sub`=admin id, `sid`=impersonation session id, `imp={…}`. Context acts as the org owner for FK
   columns (`user_id`), but audit rows record `actor_type=PLATFORM_ADMIN, actor_id=admin, user_id=NULL`. READ_ONLY blocks
   non-GET (403); FULL_SUPPORT = FULL except billing/roles_rbac/members (READ). Each mutating request writes
   `platform_audit_logs(action=IMPERSONATED_REQUEST)`. Personal routes refuse impersonation tokens.
6. **Membership statuses** ACTIVE|SUSPENDED|REVOKED|EXPIRED; removal = REVOKED (+ user ACL rows deleted); re-invite reactivates.
   Invitation statuses add CANCELLED. Non-member org header → 403 FORBIDDEN; missing/invalid header → 400.
7. **ACL:** `require(..., acl_resource=…)` admits module-NONE users holding a grant; services filter with `acl_list_filter`.
8. **Org creation** checks slug/code as owner, then `SET LOCAL ROLE` for all inserts/seeding (RLS WITH CHECK validates every
   seeded row). New orgs start on FREE_TRIAL, status TRIAL, 14 days. UT states get "Output/Input UTGST" ledger names.
9. **Month folder name** `"{MM} - {Full month} {YYYY}"` (e.g. `09 - September 2026`); FY label `FY 2026-27`.
10. **Cron** also purges idempotency keys > 24h; calibration DUE_SOON window 15 days.
11. **Clarifications applied** (plan §7): raw-body local PUT, recovery codes `xxxx-xxxx`, OAuth callback redirects to
    `/login?error=oauth_failed|oauth_disabled` and `/auth/callback?next=…` on success (start still 404s when unconfigured),
    enabled_modules always carries all 6 keys.
12. **FastAPI 0.165** keeps included routers nested; use `app.main.iter_api_routes(app)` to enumerate routes.
13. Karnataka PT seeded per spec (≥ ₹15,000 → ₹200); all statutory values are editable configs.
