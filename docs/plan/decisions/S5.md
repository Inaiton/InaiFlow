# S5 — Superadmin: decisions & deviations

1. **Files.** `router.py` (all 34 `/admin/*` ops), `service.py` (dashboard, orgs, users, system, meta), `service_auth.py`,
   `service_configs.py`, `service_billing.py` (plans, invoices, audit, admins), `repository.py`, `config_schemas.py`,
   `template_tokens.py`, `audit.py`. No migration needed (0005 stays a no-op; drift test green).
2. **Admin auth.** Login always returns a challenge: `PASSWORD_CHANGE_REQUIRED` (when `must_change_password`; also carries
   `otpauth_uri` while MFA is unenrolled) → `MFA_SETUP_REQUIRED` (pending secret Fernet-encrypted, kept stable across retries)
   → `MFA_REQUIRED`. `mfa/verify` enrolls MFA on the first valid TOTP and enforces the password policy + "differs from
   temporary" for the forced change (other sessions revoked). Rate limit reuses `core.ratelimit` under the key
   `admin:<email>` (separate from tenant users). Refresh: `if_art` (HttpOnly, Secure except dev/test, SameSite=Strict,
   Path `/api/v1/admin/auth`), **12 h TTL**, hashed in `admin_sessions`, rotation via atomic UPDATE, replay of a rotated token
   revokes the family, requires `X-Requested-With: inaiflow`. Deactivated admin: login/verify/refresh → 403
   `ACCOUNT_SUSPENDED`; bearer tokens die because deactivation revokes sessions (core guard → 401). Every admin route checks
   the IP allowlist (public auth routes call `check_admin_ip`). Successful verify writes `ADMIN_LOGIN`.
3. **Audit.** Every mutation → `write_platform_audit` via `superadmin/audit.py` (IP sanitized); the typed reason is stored as
   `after_state.reason` (the table has no reason column; contract `PlatformAuditOut` unchanged).
4. **Boundaries.** Tenant-data *mutations* go through new append-only interface functions (listed in requests/S1.md):
   identity (suspend/unsuspend, MFA reset, verify email, revoke sessions, session count) and organization (status, plan,
   owner transfer, memberships). **Documented exception — platform reporting reads:** directory/detail/dashboard counts are
   read-only cross-tenant SQL in `superadmin/repository.py` (orgs, users, memberships, vouchers, period_runs, documents),
   on the platform session. Platform control-plane tables (configs/versions/plans) are written by the console with SQL
   because their ORM models are private to `platform`; services still read effective configs via `platform.interface`.
5. **Lifecycle.** ACTIVATE (not already ACTIVE), SUSPEND (from ACTIVE/TRIAL), ARCHIVE (SUPERADMIN only, 403 for
   SUPPORT_ADMIN even though the route admits it), EXTEND_TRIAL (`trial_days` 1–365 required; from TRIAL/SUSPENDED; extends
   from max(now, trial_ends_at); status → TRIAL). SUSPEND/ARCHIVE end open impersonation sessions. Invalid transitions 409.
6. **Plan change** requires an existing plan (inactive only if already assigned); `quota_overrides` keys limited to
   `max_internal_seats|max_external_collaborators|max_storage_gb` (non-negative ints) and `enabled_modules` (6 module keys →
   bool); omitted = keep. **Owner transfer:** target must be an ACTIVE internal member (400 otherwise); old owner → ADMIN.
7. **Impersonation:** not for ARCHIVED orgs; 30-min `platform_impersonation_sessions` row; token from
   `create_impersonation_token`; `launch_url = {PUBLIC_USER_WEB_URL}/impersonate#token=…&org_id=…` (fragment only).
8. **Users:** SUSPEND revokes all sessions; actions that are no-ops (e.g. UNSUSPEND an active user, RESET_MFA without MFA)
   → 409. `org_count` = ACTIVE memberships; `memberships` lists non-revoked ones.
9. **Configs.** Payload models per (category, key) mirror `app/seeds` (all seed rows validate — parametrized test): GST_SLABS,
   TDS_SECTIONS, PAYROLL_STATUTORY/{EPF,ESIC,PT_SLABS,INCOME_TAX} (also accepted as stand-alone categories), DEFAULT_ROLES
   (permission keys/levels validated; `role_code == config_key`), ISO_WORKFLOW_TEMPLATES (node shapes, edge refs),
   DOC_REPORT_TEMPLATES, FOLDER_TEMPLATES/{MONTHLY (must keep BILLS/OPERATIONS/PAYROLL), MASTER_LIBRARY}; extra keys allowed;
   decimals must be strings. Others: any JSON object. Update = version+1, live payload replaced, version row with
   `effective_from` + reason + created_by; `get_config(on_date)` picks the latest version effective on that date.
10. **Push** only for template categories (others 409). Per org a separate tenant transaction (RLS role) calling the owning
    module's function discovered with `getattr` (requests/S4.md, requests/S1.md); missing function / failure / unknown or
    archived org → `orgs_skipped`. Today all pushes report skipped until S4/S1 add those functions.
11. **Template tokens:** catalogue lives in `superadmin/template_tokens.py`, exported as `superadmin.interface.TEMPLATE_TOKENS`;
    tokens include braces (the admin editor inserts them verbatim). `/admin/meta/template-tokens` prefers
    `documents.interface.template_tokens()` if S4 adds it.
12. **Billing:** invoice number `INV-YYYYMM-####` (issue month, gap-free per month under an advisory lock); transitions
    DUE→PAID (sets `paid_at`), DUE→VOID, PAID→VOID; others 409. Plan `enabled_modules` keys restricted to the 6 module keys.
13. **Admins:** temp password `token_urlsafe(18)` shown once, `must_change_password=true`, no MFA; you cannot change your own
    role or deactivate yourself; the last active SUPERADMIN cannot be demoted/deactivated (serialized by an advisory lock);
    deactivation revokes the admin's sessions and ends their impersonation sessions; role changes apply immediately.
14. **Dashboard:** MRR = Σ monthly price of ACTIVE orgs' plans; active runs = `period_runs.status='IN_PROGRESS'`; vouchers today =
    created since UTC midnight; storage = Σ `documents.file_size`; signups = user sign-ups per day, last 30 days (UTC);
    recent orgs = 5 newest; irp health from the tax gateway adapter.
