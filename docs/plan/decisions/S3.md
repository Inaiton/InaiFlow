# S3 — Payroll: decisions & deviations

1. **Rounding.** Earnings, ESIC employer share and PT are 2 dp (half-up). EPF employee/EPS/EDLI/admin follow EPFO rupee rounding;
   EPS = min(round(8.33% x EPF wages), cap); employer EPF = employee share - EPS ("3.67% remainder"). ESIC employee share rounds UP
   (config `employee_rounding`). TDS rounds to the rupee (annual tax and the monthly instalment).
2. **Proration.** factor = (basis - lop_days) / basis, basis from `payroll_settings.working_days_basis` = CALENDAR | FIXED_26 | FIXED_30.
   Every fixed component and other allowance is prorated. Overtime hourly = (full basic + da) / basis / 8 x 2 (constant
   `OVERTIME_MULTIPLIER`; no config key exists). Piece rate = `piece_rate` x `production_units`.
3. **EPF admin minimum** (Rs 500) is per establishment: if Σ line admin < minimum, the shortfall is added to the first EPF line (by
   emp_code), so line breakdowns always sum to run totals. EDLI capped by config `edli_cap`.
4. **ESIC** eligibility and wages = the month's actual gross (incl. OT/piece-rate); applies when 0 < gross <= `gross_ceiling`.
5. **PT.** MONTHLY states: slab on monthly gross, `feb_amount` in February (MH 300). HALF_YEARLY states (TN, Kerala): slab on
   gross x 6, one sixth deducted every month (2 dp) — a monthly equivalent instead of lump sums in Sep/Mar. Slab chosen = highest
   `min` <= income (handles 14999.99/15000 gaps). No state / `pt_applicable=false` -> 0.
6. **TDS s.192.** projected = Σ gross of earlier LOCKED/PAID runs in the FY + current gross x remaining months (incl. current);
   minus standard deduction; OLD regime also minus min(projected EPF employee, 80C cap — config `section_80c_cap`, default 150000)
   and projected PT (s.16(iii)). Slabs -> 87A rebate (marginal relief when configured) -> surcharge (no marginal relief) -> cess.
   monthly = max(annual - YTD TDS, 0) / remaining months. `monthly_tds_override` wins. HRA/80D not modelled.
7. **Breakdown keys:** earnings basic/da/hra/special/conveyance/overtime/piece_rate + other allowance names; deductions
   epf/esic/pt/tds + other deduction names; employer eps/epf_er/edli/epf_admin/esic_er. Zeros omitted. Component names must be
   unique and not reuse standard keys.
8. **Payable employees for a month** = joined <= month end and (no exit or exit >= month start) — not the `is_active` flag, so
   leavers get their final month. Default attendance: LOP = days before joining / after exit, days_present = rest.
9. **Attendance:** PUT rejects rows when the month's run is LOCKED/PAID (409), days_present + lop > days in month, unknown
   employees, allocations on non-operators, duplicate runs or shares != 100 (400); run ids validated via
   `operations.resource_names`. `pull-operations` writes shares (step count per run, 4 dp, remainder on the last) on
   non-finalized operator rows only and never finalizes.
10. **Lock** (one transaction): no payable employees or any non-finalized row -> 409 PAYROLL_NOT_READY with
    `details.missing[{employee_id, emp_code, full_name}]`; recompute; operator gross split by share (last share takes the
    remainder); operators without allocations -> DIRECT_WAGES without cost centre. Voucher dated month end, base_type PAYROLL:
    DR DIRECT_WAGES per run cost centre (+ None), DR ADMIN_SALARIES (STAFF + MANAGEMENT), DR EMPLOYER_PF_ESIC; CR SALARY_PAYABLE =
    Σ net + Σ other deductions (other deductions stay in Salary Payable for manual adjustment — no loan ledger mapping exists),
    CR EPF_PAYABLE = EE + EPS + ER + EDLI + admin, CR ESIC_PAYABLE (EE+ER), PT_PAYABLE, SALARY_TDS_PAYABLE. Balance asserted before
    posting. Payslips: PDF per line into the month's "Payroll & Statutory Challans" folder (`AUTO_PAYSLIP`, linked to the voucher).
11. **mark-paid:** LOCKED_POSTED only; PAYMENT voucher DR SALARY_PAYABLE / CR bank for total net pay; status PAID; audit action POST.
12. **Files.** Bank file: run must be locked; 400 if any employee with net > 0 lacks account/IFSC; only `format=NEFT` (CSV).
    Free-text CSV cells starting with = + - @ are prefixed with `'`. ECR: whole rupees, NCP days = LOP, refund 0, EPF members
    only; EPF/EPS/EDLI wages recomputed from stored earnings + EPF config of the month. ESIC/PT CSVs as specified; PT adds a TOTAL
    row. Statutory files are available for drafts too (preview). Payslip GET streams the stored document when
    `documents.get_document` works, else regenerates the same PDF.
13. **Audit** module `ACCOUNTS`; entities employee, payroll_settings, payroll_attendance, payroll_run (LOCK/POST/EXPORT/…).
14. No migration needed (0003 stays a no-op); line gross/total deductions are derived from the breakdown JSON.
15. Tests: `test_lock_with_real_interfaces` xfails while S2 `post_system_voucher` / S4 `store_generated_file` raise
    NotImplementedError; all lock/file logic is also covered with in-test fakes of those interfaces.
