# W3 — User web: Operations + Documents — decisions

| # | Decision | Why |
|---|---|---|
| 1 | Mutating calls pass `params: { header: {} }` (`features/*/api/params.ts` `H`) on POST/PUT. | Core `OrgPaths` makes `header` required once the optional `Idempotency-Key` is declared (requests/W1.md #1); forward-compatible with the fix. |
| 2 | `Idempotency-Key` generated once per form (`useState(crypto.randomUUID)`) for run create, step execute/skip/succeed, postings; per call for upload-url / document create. | Plan §7.2; retries reuse the key. |
| 3 | One `FlowCanvas` (`@xyflow/react`, `next/dynamic` ssr:false) + one `IsoNode` for the 5 shapes, shared by the studio (editable) and the run pipeline (read-only, status-coloured, taken edges animated with unit counts). Canvas state in a tiny `useSyncExternalStore` store (`useFlowchartCanvasStore`). | Skill rule 7; no extra deps. |
| 4 | Item `custom_fields` = flat `key → string` (`material_grade`, `drawing_rev`, `tolerance`, `cycle_time_min`, user keys) + `_defs` (typed field defs). | Template tokens `{{item.custom.<key>}}` resolve directly. |
| 5 | Diamond connections auto-assign PASS → REJECT → REWORK; branch/label editable in the edge panel. Draft autosave = debounced PUT (1.2 s) + Ctrl+S; publish = save → server validate → publish. Published = read-only + "Create new version". | Calm, guided editing. |
| 6 | Quick QC sends only operator-entered readings with `quick_qc: true`; server fills nominals (`auto_filled`). Client shows the same autofill ("Auto · nominal") and live in/out-of-tolerance (pure `lib/tolerance.ts`). | Plan §3.8 rule stays server-authoritative. |
| 7 | Shop-floor view is a route (`/operations/runs/[runId]/floor`) reusing `StepEntryForm`. | Ops-Floor-Mobile without a second form. |
| 8 | Documents exposes `features/documents/public.ts` (pickers, upload hook, templates, saveBlob); operations imports only that. Documents reads run/step/item context through the operations HTTP API, never operations code. | Frontend counterpart of `interface.py`. |
| 9 | PDFs preview via "Open preview" (new tab, signed URL); images inline. | CSP has no `frame-src` (requests/W1.md #2). |
| 10 | Uploads use XHR raw PUT with ticket headers for progress, then `complete-upload`. | fetch has no upload progress; plan §7.1. |
| 11 | Scanner: getUserMedia (environment camera) or photo picker → canvas rotate / margin crop / grayscale contrast stretch → `pdf-lib` A4 PDF → `CAMERA_SCAN` upload; default folder = current month "Bills & Vouchers" (walk FY → month → `system_kind`), or `?folder/run/step/voucher`. OCR deferred (no `ocr_text`). | Brief. `// shortcut`: no auto edge detection; upgrade with a CV lib if users ask. |
| 12 | Report wizard: `/documents/reports/new` (template + run/step, defaults to latest active run) → `POST /documents` (server renders tokens) → `/documents/editor/[id]` (block editor + live preview, autosave PATCH, empty `qc_table` blocks pre-filled from the linked step with nominal AUTO rows) → `/review` (quick checks, ISO stamps, approval actions, PDF/DOCX). `/documents/editor/new` redirects to the wizard. | "Make inspection reports the easiest thing". |
| 13 | Block types rendered: heading, paragraph, kv, table, qc_table (`rows: {parameter, spec, observed, auto, result}[]`), checklist, signature, image (`document_id` → signed URL), divider, page_break. React elements only. | Matches server seeds; see contract request. |
| 14 | Template token picker copies `{{token}}` to the clipboard. | No cursor-insertion plumbing into controlled inputs. |
| 15 | Monthly folder rule edits `content_schema.custom` (`[{name, children?}]`) of the org's MONTHLY_FOLDER_RULE template; system sub-folders shown locked. | Seed format `{subfolders, custom}`. |
| 16 | Segregation-of-duties / invalid-state errors on approval are rendered inline with plain-language copy. | Brief. |
